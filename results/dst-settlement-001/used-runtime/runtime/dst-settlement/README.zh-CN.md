# DST 科学营地任务 v1

目标是在第 3 天清晨建立可持续的科学营地。使用真实离线 DST、Wilson、固定 seed 341784114 和原始完整世界存档；从第 1 天清晨、空背包和满状态开始，经历两夜。真实时间运行，每个游戏日约 480 秒；模型思考也消耗游戏时间。

这是一项新任务，旧 `dst-first-night-v1` 的 1.00 成绩仍然有效。不得根据新模型结果事后修改本版本的阈值或权重。首轮定位为任务难度试验，不代表已验证成功率；尚无经过完整验证的成功 oracle。

终局条件：未死亡，生命≥100、饥饿≥75、理智≥100；自己的科学机器和相距≤12单位的火坑仍存在；人在该科学机器12单位内；自制背包仍装备、自制长矛仍持有；背包和随身库存合计木材≥6、草≥6、树枝≥4、按当时新鲜度计算的可食食物饥饿值≥25。终局条件要求同时成立，不用历史最大库存代替现存储备。

死亡立即结束，已获得里程碑保留，最多0.75。环境作弊状态判 invalid、得0；缺少终止事件属于未完成的基础设施异常，不冒充有效失败。重复制作/拾取不能重复计分。`reward.py` 单独报告二值 success。

## 接口与预检

模型只见25单位半径的结构化观察，最多90个附近实体。新增原生挖矿、科技原型制作、背包库存与食物/耐久信息；提供原生攻击供防御。只允许观察列出的配方；材料消耗、科技距离、寻路和动作动画均由游戏引擎执行。视频是证据，模型不接收视频帧。

桥接层关闭桌面键鼠对角色的控制，避免远程输入残留打断模型动作；没有改变移动速度、耗材、生命或战斗规则。`bootstrap.lua` 仅在正式开始前使用：恢复完整存档后，将时钟、生命/饥饿/理智和起点规范化为原始初始观察中的第1天清晨、满状态、`x=-264.53506469727,z=-197.64739990234`，随后暂停等待首个 observe。正式开始后不再执行此准备脚本。

`preflight.lua` 是隔离的机制冒烟检查，会在可丢弃的测试世界中生成测试材料与矿石；它不是评估轨迹，也不是自然资源 oracle。正式运行必须结束该世界、恢复只读完整基线、重启客户端，确保预检实体、科技解锁、状态和记忆均不进入正式试验。预检全图资源计数也不能提供给模型。

运行目录和端口与旧任务分离：游戏容器 `/home/steam/dst-settlement-v1/`，状态/动作桥18775，模型代理18776。部署到新的宿主机目录并使用 `configs/dst-settlement500k.yaml`。模型仍为 `deepseek-flash`，OpenCode上下文500000，输入495904、输出4096，thinking enabled、reasoning effort low；累计token截断关闭，墙钟上限1800秒。

启动时原生关闭启动面板后检查游戏确认；确认失败时不得继续接受空状态动作。记录完整录像、原始API响应、实际用量、所有动作及反馈、状态和独立事件、任务及代码哈希。评分代码、任务描述与配置须在首个模型请求前封存。第一次试跑后只解释结果；协议变更必须另起版本。
